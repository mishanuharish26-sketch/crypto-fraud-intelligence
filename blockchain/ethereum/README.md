# Ethereum Blockchain Module

This module retrieves and normalizes Ethereum blockchain transaction
and asset-transfer data for the Crypto Fraud Intelligence platform.

## Input

- Ethereum wallet address

## Output

- ETH transfers
- ERC-20 transfers
- NFT transfers
- Transaction hash
- Sender
- Receiver
- Block number
- Timestamp
- Asset
- Value

## Provider

Alchemy Ethereum API
